# BU CDS Public Research Data

Free, public download links for research datasets from Boston University's Faculty of Computing &
Data Sciences (CDS). Anyone can download, with no account and no login.

Catalog: [data.cds.bu.edu](data.cds.bu.edu)

## How it works

1. A CDS researcher asks the data steward to publish a dataset approved for public release.
2. The steward uploads it to the Open Storage Network (OSN), provided free through NSF ACCESS.
3. The dataset appears on the catalog page with a direct download link for each file.

## Good to know

- **Public only.** No HIPAA, FERPA or export-controlled data.
- **Not an archive.** OSN keeps no backups. Researchers keep the master copy; for a citable DOI,
  also deposit the dataset in a repository such as Zenodo.
- **Status:** demo. The listed datasets are public data re-hosted from their original sources.
- **For scripts:** `catalog.json`, next to the page, lists every dataset, file, checksum and
  citation.
